🔬 研究方向

LLM Post-Training Adaptation 五年规划 · Jiaxin Luo

核心命题

如何让大语言模型在部署后持续适应动态环境，同时保持基础能力不遗忘？

这包括：新任务到来时的快速适应、用户反馈的实时整合、领域知识的增量更新、以及跨设备/跨场景的能力迁移。

五个子方向

1. 持续学习（Continual Learning）

2026-2027 · 核心

模型如何顺序学习多个任务而不遗忘旧能力。重点：参数高效方法（LoRA/Adapter）、回放策略、模型合并。

2. 测试时适应（Test-Time Adaptation）

2026-2027 · 核心

在推理阶段利用无标签测试数据实时调整模型。重点：熵最小化、伪标签、批归一化统计量更新。

3. 在线强化学习（Online RLHF / DPO）

2027-2028 · 扩展

根据用户实时反馈持续优化对齐。重点：偏好学习、策略梯度、探索-利用权衡。

4. 参数高效微调（PEFT / MoE）

2026-2028 · 基础

用最少参数实现最大适应。重点：LoRA 变体、Mixture of Adapters、动态专家选择。

5. 模型编辑与知识更新（Model Editing）

2027-2029 · 前沿

精确修改模型中的特定知识而不影响其他能力。重点：ROME、MEMIT、知识定位。

  • UbiComp 2026：NeuroLoop 边缘部署（BCI 验证场景）
  • 目标：3 篇一作顶会，建立"表示空间指纹"方法论

Year 2 (2027-2028)：系统下沉

  • ContinualEdge Runtime 开源（端侧持续学习运行时）
  • ASPLOS / MobiSys：边缘设备上的模型生命周期管理
  • NeurIPS / ICML：端云协同的持续学习理论
  • 目标：从算法到系统的完整闭环，GitHub 1000+ stars

Year 3 (2028-2029)：应用扩展

  • 多领域落地：电梯维保 → 电力巡检 → 医疗质控 → 建筑施工
  • CHI / CSCW：人机交互视角的边缘 Agent 设计
  • 目标：3+ 行业验证，形成"端侧 AI 中间件"产品化路径

Year 4-5 (2029-2031)：理论突破

  • 持续学习的理论上限分析（遗忘下界、迁移上界）
  • 与神经科学结合：人脑持续学习的启示
  • 目标：博士毕业，入职大厂核心研究岗或创业

与 BCI 的交叉

LLM Post-Training 和 BCI 跨被试迁移本质上是同一个数学问题：分布偏移下的快速适应。我计划：

  • 用脑电信号的"生理指纹"启发 LLM 的"任务指纹"设计；
  • 用 LLM 的模型合并技术解决 BCI 的多被试知识融合；
  • 最终目标：一个统一的"自适应智能"理论框架，同时覆盖人工神经网络和生物神经网络。
