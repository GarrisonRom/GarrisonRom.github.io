版本锁定策略

  • Go 模块：go.mod 精确到 patch 版本；
  • Python：requirements.txt + conda env 导出；
  • Docker：镜像 tag 精确到 digest，不用 latest；
  • 模型：GGUF 文件记录 sha256，防止 OTA 更新后行为不一致。
