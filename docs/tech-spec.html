📘 ContinualEdge 技术规范

v1.0-draft · 领域无关的端侧 Agent 运行时设计 · Jiaxin Luo

1. 设计原则

  • 领域无关（Domain-Agnostic）：Runtime 不感知具体业务，只管理 Domain Adapter 的生命周期；
  • 离线优先（Offline-First）：所有核心功能在无网络环境下必须可用；
  • 持续自适应（Continual Adaptation）：支持端侧增量学习与模型合并，无需回云端重训；
  • 资源受限（Resource-Constrained）：目标设备内存 << 3GB，无 GPU，ARM Cortex-A53/A73。

2. 核心抽象

2.1 Domain Adapter Card

每个任务域的标准化描述文件（JSON Schema）：

{
  "$schema": "https://garrisonrom.dev/schemas/adapter-card-v1.json",
  "domain_id": "string",           // 全局唯一标识
  "domain_version": "1.0.0",       // 语义化版本
  "fingerprint": {
    "layer_stats": {               // 层-wise 统计指纹
      "layer_{i}": {
        "mean": [float],           // 维度 = hidden_size
        "cov": [[float]],          // 维度 = hidden_size × hidden_size
        "sample_count": int
      }
    },
    "cka_signature": [float],      // 预计算的 CKA 对角线签名
    "w2_signature": [float]        // 预计算的 W2 距离签名
  },
  "adapter_weights": {
    "format": "gguf-lora",         // 仅支持 GGUF LoRA
    "path": "string",              // 本地文件路径或远程 URL
    "checksum": "sha256:...",      // 完整性校验
    "size_bytes": int
  },
  "tool_registry": [               // 该 Domain 可用的工具列表
    {
      "tool_id": "string",
      "description": "string",
      "parameters": { /* JSON Schema */ },
      "required_permissions": ["camera", "microphone", "location"]
    }
  ],
  "training_stats": {
    "samples_seen": int,
    "last_updated": "ISO-8601",
    "merge_count": int,
    "parent_domains": ["domain_id"]  // 合并血缘追踪
  },
  "resource_quota": {
    "max_memory_mb": int,          // Adapter 运行时内存上限
    "max_compute_ms": int,         // 单次推理计算时限
    "priority": int                // 调度优先级 1-10
  }
}

2.2 Runtime API 接口

Android/Kotlin 层通过 JNI 调用 C++ Runtime 的核心 API：

// 初始化 Runtime
CEStatus ceInit(CEConfig* config);

// 加载 Domain Adapter
CEStatus ceLoadAdapter(const char* domain_id, CEAdapterHandle* out);

// 执行推理（自动调度最匹配的 Adapter）
CEStatus ceInfer(const char* input_text, CEInferenceResult* out);

// 触发端侧学习（Few-shot 微调）
CEStatus ceLearn(const char* domain_id, CESample* samples, int n);

// 执行 Adapter 合并（后台线程）
CEStatus ceMerge(const char* domain_a, const char* domain_b, const char* new_domain_id);

// 获取当前内存/功耗状态
CEStatus ceGetStatus(CEStatusReport* out);

4. 端云同步协议

4.1 差分更新（Delta Sync）

法规库/模型更新时，不推送全量，只传差异：

// 云端生成 delta
{
  "base_version": "1.2.0",
  "target_version": "1.2.1",
  "delta_format": "bsdiff",        // 或 zstd-dict
  "delta_size": 204800,            // 200KB
  "checksum": "sha256:...",
  "chunks": [
    {"offset": 1024, "data": "base64..."},
    {"offset": 4096, "delete": 512}
  ]
}

4.2 断点续传

  • 模型分片：每片 5MB，带独立校验和；
  • UploadID 机制：端侧持久化已传 Parts，重启后继续；
  • 幂等键：{device_id}:{timestamp}:{random}。

5. 安全规范

  • 传输：执法仪 ↔ 后端 mTLS 双向证书；
  • 存储：照片 MinIO SSE-S3 加密，PG 敏感字段 AES-256-GCM；
  • 证据链：每张照片 SHA-256，Event HMAC-SHA256 签名；
  • 防伪：pHash 感知哈希检测重复上传；
  • JWT：技师 Token 短期（2h）+ Refresh（7d），设备指纹绑定（IMEI + SN）。

6. 领域适配指南（Domain Porting Guide）

新领域接入仅需四步：

  1. 定义 Domain：编写 domain_config.json（任务划分、法规源、工具列表）；
  2. 收集知识：下载公开法规 PDF，跑预处理脚本（PyPDF → 切分 → 向量化）；
  3. 训练初始 Adapter：云端用 50-100 条合成样本训 LoRA，导出 GGUF；
  4. 注册 Card：计算指纹，生成 Adapter Card，推送到端侧。

预计工作量：2 周/领域。
